# Cars24 - Used Car Price Prediction

Predict the selling price of a used car and serve the model in a Streamlit app.

- `data/cars24-car-price.csv` - dataset
- `cars24_ml.py` - Streamlit app (loads the pickled model `car_pred`)
- `assignment/` - MCQ assignment, answer key and coding answers

```bash
pip install -r requirements.txt
streamlit run cars24_ml.py
```
