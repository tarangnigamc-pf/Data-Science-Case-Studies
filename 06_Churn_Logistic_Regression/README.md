# Telecom Churn - Logistic Regression

Predict whether a telecom customer will churn (AT&T use case, 5,700 customers, 20 features).

- `notebooks/8_Notes_Logistic_1.ipynb` - problem, data dictionary, sigmoid, log-loss, MLE
- `notebooks/9_Notes_Logistic_2.ipynb` - sklearn implementation, tuning, log-odds, outliers, multi-class
- `notebooks/10_Classification_Metrics_1_Notes.ipynb` - confusion matrix, precision, recall, F1 (uses the spam datasets)
- `data/churn_logistic.csv` - churn dataset
- `data/spam_ham_dataset.csv`, `data/Spam_finalData.csv` - spam datasets used in the metrics notebook
