# Porter - Delivery Time Estimation

Predict the delivery time of an order from the restaurant, order and delivery-partner availability features.

- `Problem_Statement.docx` - context, data dictionary and tasks
- `solution/Porter_Delivery_Time.ipynb` - EDA, feature engineering and models (random forest, neural network)
- `data/porter_dataset.csv` - dataset linked from the problem statement
- `data/data_2.csv` - the dataset the solution notebook loads (same schema, partner columns are named `dashers`)
